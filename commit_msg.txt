test: add Protein PDB serialisation roundtrip test

No test existed that exercised the full serialize-then-parse path
through to_pdb / protein_from_pdb. Since that path is lossy (absent
atoms are dropped; b_factors are overwritten with molecule-type
encoding on parse), subtle bugs could go undetected.

The new roundtrip_protein fixture is purpose-built for this test:
atom positions are pre-rounded to three decimal places to match the
PDB %8.3f column width, so atom_positions can be asserted with exact
equality rather than an approximate tolerance. Absent-atom positions
are zeroed, so the full (N_res, 37, 3) array can be compared without
masking. GLY is included as the last residue to exercise the
CB-absent code path.

The b_factors assertion checks float(MOL_TYPE_PROTEIN) on the
recovered object rather than comparing to the fixture's zeros.
protein_from_pdb unconditionally replaces b_factors with molecule-
type encoding; the assertion documents that contract explicitly
instead of relying on a numerical coincidence.

Also replace np.random.randn in long_np_example with a seeded
np.random.default_rng to clear the NPY002 ruff warning.
